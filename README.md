# Level-Up 🚀

A modern productivity, task tracking, and self-improvement web application built for students and developers.

## 🛠️ Tech Stack
* **Frontend:** TypeScript, React (TanStack Start), Tailwind CSS, Vite
* **Backend & Database:** Supabase (PostgreSQL, PL/pgSQL, Row Level Security)
* **Hosting & Edge Deployment:** Cloudflare Workers

## ✨ Key Features
* **Task & Life Management:** Organize tasks, notes, and academic schedules in one unified dashboard.
* **Student Hub Support:** Track courses, assignments, and exam deadlines with custom database relations.
* **Focus Analytics:** Log study sessions and view productivity trends over time.
* **Local & LAN Ready:** Optimized for seamless local development and multi-device access across local networks.
